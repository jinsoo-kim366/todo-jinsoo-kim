# jinsoo-kim의 할 일 목록

마감일과 작성자를 붙여 관리하는 간단한 할 일 앱이에요. 할 일은 Supabase 데이터베이스에 저장돼요.

사이트: https://todo-jinsoo-kim.vercel.app

## 기능

- 할 일 추가 (작성자 이름, 마감일은 선택)
- 마감일 표시: `D-3`, `D-day`, `D+1`처럼 남은 날짜를 보여 주고, 2일 이내는 파란색, 지난 것은 빨간색
- 마감이 가까운 순으로 정렬 (마감일 없는 할 일은 맨 아래)
- 할 일 글자를 두 번 누르면 수정 (Enter 저장, Esc 취소, 내용을 모두 지우면 삭제)
- 전체 / 진행 중 / 완료 필터 버튼
- 요약 개수: 전체 · 남은 · 완료
- 화면 색 바꾸기: 제목 오른쪽 버튼으로 자동 / 라이트 / 다크를 고르고, 고른 색은 다음에도 기억함
- 목록 오른쪽 공부 조언 칸: 10초마다 부드럽게 다음 조언으로 바뀜 (좁은 화면에서는 제목 아래)
- Supabase에 저장되어 새로고침해도 그대로 남아 있음

## 사용한 기술

- HTML, CSS, JavaScript (빌드 과정 없음)
- [Supabase](https://supabase.com): 데이터베이스 (`supabase-js` v2를 CDN으로 불러옴)
- [Vercel](https://vercel.com): 사이트 배포

## 파일 설명

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 화면 구조 (제목, 입력 칸, 필터 버튼, 목록) |
| `style.css` | 디자인 (다크 모드 포함) |
| `app.js` | 할 일 불러오기·추가·수정·삭제, 필터, 정렬, 화면 그리기 |
| `config.js` | Supabase 주소와 publishable key |

## 내 컴퓨터에서 실행하기

1. 이 저장소를 내려받아요.
2. 브라우저로 `index.html`을 열어요.

Supabase 주소와 키는 `config.js`에 들어 있어서 따로 설정할 것은 없어요.

## 데이터베이스 표 (`todos`)

| 칸 | 종류 | 설명 |
| --- | --- | --- |
| `id` | 숫자 | 할 일 번호 |
| `text` | 글자 | 할 일 내용 |
| `done` | 참/거짓 | 완료 여부 (기본값: 거짓) |
| `created_at` | 날짜·시간 | 추가한 시각 (자동 기록) |
| `author` | 글자 | 작성자 이름 (선택) |
| `due_date` | 날짜 | 마감일 (선택) |

## 보안 안내

- `config.js`의 publishable key는 브라우저에 공개되어도 되는 키예요. 비밀 키(secret key)는 이 저장소에 없어요.
- 다만 지금 데이터베이스 접근 규칙은 누구나 모든 할 일을 읽고, 추가하고, 고치고, 지울 수 있게 되어 있어요. 연습용으로는 괜찮지만, 실제 데이터를 넣으려면 로그인을 붙이는 등 규칙을 더 엄격하게 바꿔야 해요.
